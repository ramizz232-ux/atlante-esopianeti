# Atlante Esopianeti Abitabili

Mappa 3D navigabile della Via Lattea con gli esopianeti potenzialmente abitabili e tutti i sistemi del NASA Exoplanet Archive. Funziona nel browser e si installa sul telefono come app (anche offline).

**Apri:** https://ramizz232-ux.github.io/atlante-esopianeti/

Installazione sul telefono:
- iPhone (Safari): Condividi → Aggiungi alla schermata Home
- Android (Chrome): menu ⋮ → Installa app
